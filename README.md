# Gravity Sandbox

Интерактивная необычная гравитационная симуляция с настраиваемой физикой, свойствами планет и границами. Размещайте планеты, задавайте начальные скорости и наблюдайте, как они движутся под действием гравитации.

## Возможности

- **Несколько гравитационных функций**: квадратичная (r²), линейная (r), степень 3/2 (r^1.5), экспоненциальные варианты (e^(√r/4), e^(∛r), e^(⁴√r)).
- **Настраиваемые параметры**: гравитационная постоянная, центральная масса, количество планет (1–9), радиус планет, максимальная сила, максимальная скорость, множитель масс.
- **Типы границ**: тороидальная (зацикленная), отскок от краёв, ограничение радиуса (круг).
- **Режим ручной расстановки**: перетаскивайте для задания положения и начальной скорости.
- **Загрузка / сохранение конфигураций**: загружайте состояния планет из текстового файла; сохраняйте после ручного режима.
- **Индивидуальные настройки планет**: собственная масса и цвет для каждой планеты.
- **Регулировка параметров в реальном времени**: используйте клавиши со стрелками (или сенсорные зоны), чтобы изменять гравитационную постоянную и центральную массу во время симуляции.
- **Двуязычный интерфейс**: английский / русский (переключаемый).
- **Адаптивный дизайн**: работает на компьютерах и мобильных устройствах (оптимизировано для сенсорного управления).
- **Высокоточная физическая симуляция**: метод расчёта гравитации — Velocity Verlet. Общее количество гравитационных подшагов в секунду =  
  (базовые шаги (10–90) × сложность ситуации (1–8)) × (число кадров в секунду, FPS). Максимальное количество подшагов в секунду (при 60 fps) = 14 400.

## Как играть

1. Откройте игру в браузере.
2. Настройте параметры на главном экране:
   - Выберите гравитационную функцию, количество планет, режим запуска (случайный статический или ручное перетаскивание).
   - Установите тип границы и тип столкновений.
   - Настройте дополнительные параметры через кнопку **Настройки** (радиус планет, максимальная сила, центральная масса и т.д.).
   - Точная настройка массы и цвета каждой планеты — в разделе **Настройки планет**.
3. Нажмите **Запустить игру**.
   - В режиме **Случайный статический** планеты размещаются случайным образом с нулевой начальной скоростью.
   - В режиме **Ручной ввод** вам будет предложено разместить каждую планету, перетаскивая на холсте:
     - Нажмите / коснитесь, чтобы задать положение планеты (появится круг).
     - Перетащите, чтобы нарисовать вектор начальной скорости (длина стрелки = скорость).
     - Отпустите, чтобы создать планету.
     - После размещения всех планет вас спросят, сохранить ли конфигурацию.
4. Наблюдайте за симуляцией! Используйте клавиши со стрелками (или сенсорные зоны), чтобы подкручивать гравитационную постоянную и центральную массу в реальном времени.
5. Дважды нажмите / коснитесь центральной области или нажмите `Escape`, чтобы вернуться в главное меню.

**Во время режима ручной расстановки**:

- Используйте клавиши со стрелками для перемещения курсора, `Space`/`Enter` для размещения, `Escape` для отмены.
- Перетаскивайте мышью / пальцем, чтобы задать скорость.

## Формат конфигурационного файла

При сохранении или загрузке конфигурации (файл `.txt`) формат следующий:

N F G C M W H

m1 x1 y1 vx1 vy1

m2 x2 y2 vx2 vy2

...

- `N` : количество планет (1–9)
- `F` : тип гравитационной функции (1–6)
- `G` : гравитационная постоянная
- `C` : центральная масса
- `M` : множитель масс планет (применяется ко всем указанным ниже массам)
- `W` : ширина мира
- `H` : высота мира
- Для каждой планеты: `масса x y vx vy` (масса — это базовая масса, до применения множителя)

## Несколько замечаний:

Раньше у планет были следы, но это мешало визуальному восприятию (на мой взгляд), поэтому я от них избавился.

Причина, по которой все планеты имеют одинаковый радиус, заключается в том, что гравитация рассчитывается между центрами планет. Если бы радиусы были разными, возникли бы проблемы с физикой в режиме «упругое столкновение».

## Установка

1. Скачайте файл `gravi.html` из репозитория.
2. Откройте его в любом современном веб-браузере (Chrome, Firefox, Edge, Safari).
3. Сервер или подключение к интернету после скачивания не требуются.

## Разработка

Игра написана на чистом HTML, CSS и JavaScript (ES6) без использования внешних библиотек. Вся физика и интерфейс реализованы самостоятельно.  
Особенно приветствуются новые стартовые txt-конфигурации.
